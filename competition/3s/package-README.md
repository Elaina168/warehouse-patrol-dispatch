# 仓巡智调

## 平台简介

“仓巡智调”是面向动态仓储的多机器人在线调度与安全决策平台。平台在仓储网格中统一管理机器人、任务、货架库存、通道状态、事件和运行指标，并通过在线会话持续更新任务分配、机器人路径与执行状态。

平台包含任务分配、A*路径规划、时空预约、冲突检测、运行时重规划、库存状态和历史回放等功能，适合进行仓储巡检、入库配送、出库配送和应急复核演示。

## 启动平台

1. 双击 `WarehousePatrol\WarehousePatrol.exe`。
2. 等待本机服务启动，默认浏览器会打开平台页面。
3. 桌面窗口会显示本机访问地址和“停止服务”按钮。
4. 演示结束后点击“停止服务”或关闭桌面窗口。

## 默认场景

平台默认打开“综合调度演示”场景，地图为 26×16 网格，配置 4 台机器人和 6 项场景任务。

- T=0：T1、T2、T3 进入任务队列；
- T=4：T4 进入任务队列；
- T=8：T5 进入任务队列；
- T=12：场景动态机制触发，E1 进入调度。

任务到达、通道封锁、机器人故障、任务追加、机器人恢复和机器人退役均可通过平台控制面板操作。平台会同步显示任务队列、机器人路径、库存、事件日志和指标历史。

## 使用说明

### 1. 启动与运行

程序启动后会自动创建当前场景的在线会话。等待页面状态显示平台在线、地图和任务数据加载完成后，即可操作。点击“播放”按时间推进仿真，点击“暂停”保留当前时间；“播放速度（tick/s）”可调整演示速度。点击“重置”或顶部“重新规划”可将会话恢复到初始状态，重新开始演示。

### 2. 地图运行时操作

- 在地图上的可操作空白单元格右键，选择“封锁此单元”。平台会识别受影响的任务和路径，重新分配任务并生成路径，相关变化会写入“重规划解释”和“事件日志”。
- 在已封锁单元格上右键，选择“解除封锁”，平台会重新检查可达性并同步任务、路径和指标。
- 在机器人图标上右键，选择“标记 Rn 故障”。该机器人会从当前可用调度池中移出，受影响任务交由其他符合能力、载重和可达性条件的机器人处理。
- 在故障机器人图标上右键，选择“恢复 Rn”。平台记录恢复事件，并重新同步机器人状态、任务分配和路径。

### 3. 接入与管理机器人

在“机器人接入”面板填写机器人 ID、名称、接入位置、电量、电池上限、载重、每格移动 tick 和能力（巡检、取送、突发）。坐标可直接输入 `x, y`，也可点击坐标栏右侧的定位按钮后在地图上选择。点击“接入机器人”后，机器人按当前仿真时间加入会话，平台随即重新计算调度结果。

机器人状态会显示在“当前机器人管理”列表中。确认机器人处于空闲状态后，可点击对应的“永久移除”并确认操作。移除后的机器人停止参与任务分配、路径规划和冲突检测，其退役前的路径、事件和指标历史仍保留在当前会话中。

### 4. 追加在线任务

在“在线任务”面板选择“巡检”“取送”或“突发”，填写标题、优先级、截止 T 和作业时间。巡检、突发任务填写“目标”坐标；取送任务分别填写“取货”和“送达”坐标。坐标既可按 `x, y` 输入，也可使用定位按钮从地图选择。点击“推入任务队列”后，任务通过在线任务入口加入当前队列，平台会结合机器人能力、电量、载重、可达性和当前路径状态重新规划。

### 5. 随机事件与结果查看

勾选“随机事件生成器”中的“自动生成并推入任务队列”，设置“生成间隔（tick）”，再点击“播放”。仿真运行到相应时间时，平台会自动生成在线任务并加入队列；取消勾选即可停止自动生成。

运行过程中可在地图查看机器人位置与路径，在任务队列查看任务状态，在“重规划解释”查看调度变化，在“事件日志”查看任务到达、封锁、故障、恢复和移除记录，在指标区域查看冲突、失败、截止和库存等运行结果。

### 6. 推荐演示时间线

默认场景按以下时间推进任务：T=0 时 T1、T2、T3 入队，T=4 时 T4 入队，T=8 时 T5 入队，T=12 时场景动态机制触发并将 E1 纳入调度。需要演示运行时事件时，可在相应时间执行地图封锁、机器人故障、恢复、在线任务追加和机器人接入等操作。

## 运行环境

- Windows x64；
- 可用浏览器；
- 程序自带平台运行组件；
- 平台服务使用本机回环地址运行。

源码包 `WarehousePatrol-source.zip` 用于查看项目源代码和构建文件。
