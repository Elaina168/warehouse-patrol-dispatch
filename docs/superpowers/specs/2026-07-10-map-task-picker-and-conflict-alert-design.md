# 地图选点与冲突告警设计

## 目标

减少手工任务坐标录入成本，并让在线仿真中的冲突在重规划解释区持续可读。

## 地图选点

- 每个手工任务坐标字段保留文本输入，并提供一个准星按钮进入选点状态。
- 巡检和突发任务选择目标坐标；取送任务依次选择取货、送达坐标。
- 选点状态下，左键地图中的非固定障碍单元写入对应字段；取送任务选完取货后自动切换到送达。
- 只有选点状态会截获地图左键。未选点时保留原有的机器人选择；右键封锁菜单不变。
- 已选坐标在地图上显示临时标记，直到任务提交、切换类型、场景重置或用户重新选择该字段。

## 冲突告警

- 继续使用 `DispatchResult.conflicts` 的现有结构化字段 `time`、`type`、`robots`、`cell`，不扩展 API。
- 前端在播放经过冲突 tick 时记录该冲突；本次会话内最新记录持续显示在重规划解释区。
- 最新冲突显示时间、顶点/边冲突类型、两个机器人 ID 和坐标；后续无冲突重规划后显示“已重规划”，但不移除该记录。
- 地图为最新冲突位置保留告警图标；若当前 tick 正处于冲突，图标显示参与机器人 ID，机器人本体改为并列色标，避免覆盖。
- 场景/会话重置时清空前端冲突记录。

## 验证

- 纯函数测试覆盖选点状态转换、坐标写入与最新冲突选择。
- 浏览器验证任务表单可从地图填写坐标，冲突提示可显示双方机器人并持续保留。
