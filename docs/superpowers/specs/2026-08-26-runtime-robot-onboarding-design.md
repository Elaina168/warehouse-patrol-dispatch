# 运行中新机器人免训练接入设计

## 目标

在线调度会话运行到任意当前时刻后，用户可以在暂停状态下接入一台经过模型校验的新机器人。机器人从真实接入时刻开始参与后续重规划，不需要训练，不改变现有任务分配、A*、时空预约避碰、冲突检测和执行安全门的边界。

## 接口与数据契约

新增 `POST /api/sessions/{session_id}/robots`，请求模型为 `AddRobotRequest`：

- `robot: Robot`：复用现有完整机器人模型和 Pydantic 约束；`robot.start` 是接入位置。
- `currentTime: SessionTimeInt = 0`：请求省略时由会话当前时间替代；请求显式提供时不得早于会话当前时间。

响应继续使用 `SessionResult`。`RobotRuntimeState` 增加以下响应字段，使前端能够同步当前完整机器人配置和生命周期：

- `start`：该机器人配置中的起始/接入位置；
- `capabilities`：完整任务类型能力集合；
- `joinedAt`：原始场景机器人为 `0`，运行时接入机器人为实际接入时间。

`DispatchResult` 增加 `pathStartTimes`。路径数组从对应机器人真实路径起点开始，前端和会话内部通过该字段解释路径数组的绝对时间偏移；运行时接入机器人不会通过复制接入位置伪造 T=0 之前的历史。

## 会话状态与事务

`DispatchSession` 保存 `robot_join_times`，创建会话和重置时为初始机器人填入 `0`。运行时接入在候选副本中完成：

1. 在现有会话锁内解析接入时间并拒绝过去时间；
2. 深复制候选会话，必要时在候选副本中推进到请求时间；
3. 校验机器人 ID、数量、位置和模型约束；
4. 将机器人加入候选 `scenario.robots`，初始化位置、相对历史、电量、里程和接入时间；
5. 清除安全停滞、失效旧规划、记录接入事件并重规划；
6. 只有结果构建成功后才把候选字段提交到权威会话。

任何校验、重规划、结果构建或提交观察器异常都不得改变权威会话的时间、路径、指标、事件、缓存或机器人集合。现有会话锁保证同一会话的重复 ID 并发请求至多一个成功。

位置允许普通可通行格和空闲充电格，拒绝越界、固定障碍、货架格、当前动态/运行时封锁格及其他机器人当前占用格。接入后机器人进入现有故障/恢复接口的机器人集合；重置从初始场景快照恢复并移除所有运行时机器人。

## 时间与回放语义

原始机器人路径历史仍以 T=0 为起点；运行时机器人历史以 `joinedAt` 为相对索引 0。运行时机器人在接入前不出现在历史地图、历史机器人运行时覆盖层、冲突和指标统计中，接入后里程从 0 开始。运行时机器人可以在后续重规划中承担新任务以及现有规则允许重新分配的待执行任务；已取货配送任务仍由既有货物进度和锁语义处理。

## 前端交互

完整操作台新增“机器人接入”面板，字段为 ID、名称、接入位置、电量、电池上限、载重、每格移动 tick 和能力复选框。接入位置支持输入和地图选点，至少选择一种能力。提交时暂停播放；历史回放、tick 请求、调度未就绪或会话不可用时禁用。成功响应直接替换当前 `SessionResult`，从响应中的机器人运行时状态同步地图、配置和事件日志；失败保留现有会话并展示后端 `detail`，不自动恢复播放。

前端通过现有会话请求协调器串行提交接入请求，使用 `addRobot` API helper 生成精确请求体。重置响应恢复初始机器人列表，接入面板的临时表单状态随会话重置清理。

## 验证范围

后端覆盖 T=0/T>0、省略时间、过去时间、重复 ID、第 33 台、越界/障碍/货架/封锁/占用位置、失败原子性、状态初始化、接入前历史隐藏、重规划参与任务、故障恢复、重置、并发、安全和冲突回归。前端覆盖 API 请求体、表单构造、地图选点、能力校验、禁用条件、成功同步、错误保留会话、接入前隐藏和重置清理。固定 `integrated-demo` 流程验证接入 R5、追加适合 R5 的任务、R5 移动并完成任务，且最终活动冲突、失败、超期和意外安全干预均为零。

不实现运行时永久删除机器人、运行时移动货架、实体通信、边缘端部署、强化学习或完整 MAPF/CBS。
