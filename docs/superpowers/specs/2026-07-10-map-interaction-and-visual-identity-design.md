# 地图交互与视觉区分设计

## 目标

消除活跃路径箭头与任务标签的冲突，为每台机器人建立一致的视觉标识，收紧单场景工具栏，并将运行时封锁操作从表单迁移到地图右键菜单。

## 范围

- 只修改前端地图渲染、工具栏、指标面板和突发事件面板。
- 复用现有会话封锁与解除封锁接口，不修改后端调度、动态触发或 API 契约。

## 箭头与机器人颜色

- 任务标签格，即显示“巡、取、送、急”的任务目标格，优先于路径箭头显示；任何落在任务标签格的活跃路线箭头都不渲染。
- 按当前场景机器人顺序生成稳定颜色。机器人圆形标识、其当前活跃路径箭头和机器人选中边框使用同一颜色。
- 同一机器人在重规划、暂停和后续 tick 中保持同色；不同机器人颜色不依赖任务分配顺序。
- 机器人悬停提示保持现有内容，只继承对应机器人颜色作为视觉标识。

## 单场景工具栏与导入

- 移除场景选择下拉框，工具栏左侧显示当前场景的大标题。
- 默认标题为“综合调度演示”。
- 导入合法场景 JSON 后，将导入场景替换为当前运行场景，重建会话并将标题更新为导入场景名称；不保留多个可选择场景。
- 保留导入和导出模板能力。

## 指标历史

- 从前端移除指标历史曲线、图例、空状态以及仅为该曲线保留的前端辅助逻辑和测试。
- 后端仍可继续维护并返回 `metricsHistory`，当前指标、运行解释和事件日志不受影响。

## 地图右键封锁

- 右键地图单元阻止浏览器默认菜单，并在鼠标附近显示轻量操作菜单。
- 普通可通行且未被机器人占用的单元显示“封锁此单元”。
- 当前运行时封锁单元显示“解除封锁”。
- 固定障碍、机器人当前占用格以及任务标签格不显示封锁操作，避免无效或影响任务标识的动作。
- 选择菜单项后调用已有会话接口；菜单关闭，前端使用返回的会话结果更新地图、任务队列、指标和路径箭头。
- 点击其他地图区域、按 Escape 或会话状态变为加载时关闭菜单。

## 重规划行为

- 动态事件跨过场景 `triggerTime` 时，后端继续自动激活动态任务、封锁和机器人故障，并使旧计划失效后生成新计划。
- 手动封锁和解除封锁也调用已有运行时接口；接口返回的会话结果已是重规划后的状态，因此前端不额外拼接或修改路径。

## 验收

- 路径箭头不会覆盖任务标签格，且每台机器人标识与箭头颜色一致。
- 初始只显示“综合调度演示”标题；导入后标题与运行场景同步切换。
- 页面无指标历史曲线。
- 右键普通单元可封锁，右键已封锁单元可解除；固定障碍、机器人和任务标签格不显示该操作。
- 动态事件、手动封锁和手动解除封锁均得到重规划后的会话结果。
- 前端测试、构建和完整项目检查通过。

## 实现验证

- 已实现：活跃路径箭头过滤任务标签格；机器人标识和其路径箭头按场景机器人顺序共用固定颜色。
- 已实现：场景下拉框替换为当前场景标题；导入场景会替换当前场景并重建会话。
- 已实现：指标历史曲线和封锁表单从前端移除。
- 已实现：普通地图单元右键显示封锁操作，已封锁单元右键显示解除封锁；菜单动作调用现有会话接口并使用返回结果更新页面。
- 页面验证：普通单元封锁后，事件日志记录 `手动封锁单元`；同一单元可从右键菜单解除封锁并恢复可通行状态。
