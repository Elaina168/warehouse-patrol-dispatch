# Demo 验收流程

本文档固定当前展示路线，避免演示时临时切换能力范围。

## 启动

```powershell
.\scripts\start-dev.ps1
```

前端地址：

```text
http://127.0.0.1:5174
```

后端健康检查：

```text
http://127.0.0.1:8011/health
```

## 推荐场景

主线演示使用唯一前端场景：

```text
integrated-demo
```

当前前端只暴露 `综合调度演示`，它把原先分散在多个场景里的能力合并到同一条仿真流程：

- 巡检任务。
- 取送任务。
- 狭窄通道避碰。
- 默认在线任务。
- 到达目标后的作业停留。
- 手动封锁。
- 手动机器人故障。
- 运行时恢复和重规划。

推荐配置：

- 启用避碰规划。
- 启用突发任务与重规划。
- 使用在线会话，而不是只展示批量调度。

## 演示步骤

1. 打开页面后确认后端状态为在线。
2. 点击播放，让时间持续推进。
3. 观察任务队列中已锁定任务，以及“重规划解释”面板中的锁定任务数量。
4. 手工加入一个紧急任务：

```text
类型：突发
优先级：5
目标：(1, 4)
作业时间：2 tick
截止时间：12
```

5. 观察事件日志中的高优先级抢占解释。
6. 手动封锁单元：

```text
(1, 2)
```

7. 观察封锁单元进入地图和事件日志。
8. 标记机器人 `R2` 故障。
9. 观察故障机器人退出调度、任务重新分配和指标变化。
10. 如需展示算法对比，在同一综合场景里切换到“基线对比”，重新规划后观察冲突数量，再切回“避碰规划”。

## 验收点

演示应覆盖以下能力：

- 在线会话创建。
- tick 推进与机器人状态更新。
- 任务目标点作业时间与完成后释放机器人。
- 任务锁定。
- 高优先级任务抢占评分。
- 运行时封锁。
- 机器人故障。
- 事件日志解释。
- 指标历史变化。
- 同一综合场景下关闭避碰会出现冲突，开启避碰可消除或降低冲突。

截至 2026-07-11，人工测试已确认：默认综合场景不会自动封锁 `(6,3)`、`(7,5)`，不会自动标记 `R3` 故障；`E1` 是默认任务队列任务；手动任务、运行时封锁/解锁、机器人故障/恢复、随机事件生成器和冲突闪烁提示的主流程可用。冲突提示优先使用后端结构化冲突状态，并会在参与机器人离开重叠格或边交换关系后从地图上消失。
